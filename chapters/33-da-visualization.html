差异图应该展示效应、不确定性和多重检验

Segata et al. (2011)用 LDA bar plot 与 cladogram 展示跨 taxonomy 层级 biomarker；现代微生物组论文还常用 volcano、按 phylum 分块的 Manhattan 和 effect-size forest plot。以下用湿地数据比较四类图各自适合回答什么问题。它们共享一份 master table，差别只在视觉任务：筛查全局、定位 lineage、观察 taxonomy block、读取效应与区间。

重要先给结论

Volcano 的远点、cladogram 的彩色分支、Manhattan 的高峰和 forest 的置信区间必须能回到同一个 FeatureID、contrast 和 q-value。图形不能重新定义显著性。主分析使用 ANCOM-BC2；cladogram 另保留 LEfSe LDA score，但对全部 tested genera 追加 BH，并明确它是辅助 taxonomy view。Forest plot 承担定量解读，其他图只负责导航。

本页使用 microeco 2.0.0 的真实湿地三件套，预声明 CW 对 IW。属级 feature selection 只看总体 prevalence 和总体 reads；未注释 residual 进入 denominator，却从四种图的生物学标注中排除。

  x <- readr::read_tsv(

    name_repair = "minimal", na = character()

四种图回答四个不同问题

Volcano：全表筛查，不是 effect uncertainty 图

横轴放 ANCOM-BC2 bias-corrected log fold change，纵轴放 \(-\log_{10}(q)\)。它同时显示方向与 statistical evidence，但不显示 standard error/CI 的宽度；极端点可能由稀疏、低 prevalence 或模型不稳定造成。标签只给预声明的少量 top rows，完整表另存。

Cladogram：taxonomy context，不是系统发育树

Kingdom→Phylum→Class→Order→Family→Genus 的分类层级不是 branch-length phylogeny。Cladogram 可显示显著 genus 所在 lineage，却不能推出进化距离，也不能让 parent 自动继承 child 的显著性。本文只给通过 BH + LDA 门槛的 genus 叶节点着色，内部节点保持中性。

Manhattan：看 taxonomy block 与集中性

横轴按 Phylum 和 genus 排序，纵轴仍是 \(-\log_{10}(q)\)。它适合发现信号是否集中在少数 phylum，也能显示 tested denominator；但 taxonomy 顺序不是连续基因组坐标，相邻点不代表遗传连锁。

Forest：给出可解释的 effect 与 95% CI

对 coefficient \(\hat\beta\) 和 standard error \(SE\)，Wald interval 为

\[ \hat\beta\pm1.96\,SE. \]

Forest plot最接近可审稿的定量图：读者能看到方向、effect size 与 precision。CI 仍依赖模型假设；它不是 absolute abundance fold change，也不能替代 raw distribution 和 sensitivity analysis。

深入：为什么 q-value threshold 与 effect threshold 要分开画

q<0.05控制的是一组检验中的错误发现期望；|log fold change|>=log(2)是本页为了标签和视觉重点预声明的 practical-effect filter。后者不改变 q-value，也不应被描述为新的显著性检验。Volcano 中分别画横线和竖线，表格同时保留 StatisticallySignificant 与 Highlighted 两列。

master_results <- data.frame(
  FeatureID = ancom_res$taxon,
  EffectCW = ancom_res$lfc_GroupCW,
  StandardError = ancom_res$se_GroupCW,
  PValue = ancom_res$p_GroupCW,
  QValue = ancom_res$q_GroupCW,
  stringsAsFactors = FALSE

master_results <- cbind(
  master_results,
  feature_info[master_results$FeatureID, c(
    "Kingdom", "Phylum", "Class", "Order", "Family", "Genus",
    "DisplayTaxon", "Lineage", "Reportable"
  )]
)
master_results$CI95Lower <- master_results$EffectCW -
  1.96 * master_results$StandardError
master_results$CI95Upper <- master_results$EffectCW +
  1.96 * master_results$StandardError
master_results$StatisticallySignificant <- with(
  master_results,
  Reportable & is.finite(QValue) & QValue < 0.05
)
practical_threshold <- log(2)
master_results$Highlighted <- with(
  master_results,
  StatisticallySignificant & abs(EffectCW) >= practical_threshold
)
master_results$Direction <- ifelse(
  master_results$EffectCW >= 0, "Higher in CW", "Higher in IW"

  kruskal.threshold = 1,
  wilcox.threshold = 1,
  lda.threshold = 0,
  groupCol = "GROUP",
  checkAbundances = TRUE
)

lefse_p <- vapply(rownames(counts), function(feature_id) {
  stats::wilcox.test(
    relative_per_million[feature_id, metadata$Group == "CW"],
    relative_per_million[feature_id, metadata$Group == "IW"],
    exact = FALSE
  )$p.value
}, numeric(1))
lefse_q <- stats::p.adjust(lefse_p, method = "BH")
descriptive_direction <- rowMeans(
  log2(counts[, metadata$Group == "CW", drop = FALSE] + 0.5)
) - rowMeans(
  log2(counts[, metadata$Group == "IW", drop = FALSE] + 0.5)
)

  FeatureID = rownames(counts),
  LDAScore = sign(descriptive_direction) * abs(lefse_scores[rownames(counts)]),

  stringsAsFactors = FALSE

常见坑

注意坑 1：四张图各筛一套 taxa

先生成 master table，再写 deterministic view rule。图中任何点都应能用 FeatureID 回查 effect、SE、p、q、lineage 和 status。

注意坑 2：用 raw p 画 volcano，却标 q=0.05

纵轴变量与门槛必须一致。若画 -log10(p)，横线就是 raw-p 门槛；本文画 -log10(q)。

注意坑 3：在 volcano 标几十个名字

标签策略要预声明并限制数量；完整结果放表。重叠标签不是删掉不喜欢结果的理由。

注意坑 4：把 cladogram 当 phylogenetic tree

Taxonomic ranks 没有 branch length，也未使用 sequence alignment。若要进化解释，应另建 ASV tree 并做 phylogenetic analysis。

注意坑 5：让内部节点继承 LEfSe 显著性

Child hit 不证明 parent 或 sibling。内部节点只提供 context；每个 rank 的证据需要独立检验。

注意坑 6：Manhattan 只画显著点

保留全部 tested rows 才能看清 denominator、taxonomy block 和选择压力。只画 hits 会制造峰值密集的错觉。

注意坑 7：Forest 只给点估计

没有 SE/CI 的“森林图”只是条形图。报告 effect unit、contrast、interval method 与失败/非有限行。

注意坑 8：颜色方向在不同图中反转

固定正值 = CW higher、红 = CW、蓝 = IW；Methods、图例和结果表共享同一 mapping。不要按软件默认 level 临时换色。

Publication figures were generated from a single prespecified genus-level differential-abundance master table. ASVs were aggregated by complete taxonomic lineage; genera present in at least 10% of the 60 CW/IW samples and represented by at least 20 total reads were eligible, and 80 rows were retained using a group-blind prevalence × log(1 + total reads) score (79 reportable genera plus one non-reportable denominator residual). ANCOM-BC2 2.6.0 was fitted with Group as a fixed effect, IW as the reference, BH correction, and seed 20260733. Effects were oriented so that positive values indicated higher abundance in CW. Statistical significance was defined as q < 0.05; a prespecified |log fold change| >= log(2) threshold was used only for visual highlighting. Volcano and taxonomic Manhattan plots displayed all reportable tested genera. The forest plot displayed the 16 smallest-q significant genera with model-based Wald 95% confidence intervals. ## 差异图应该展示效应、不确定性和多重检验 {#sec-target}

[Segata et al. (2011)](https://doi.org/10.1186/gb-2011-12-6-r60)用 LDA bar plot 与 cladogram 展示跨 taxonomy 层级 biomarker；现代微生物组论文还常用 volcano、按 phylum 分块的 Manhattan 和 effect-size forest plot。以下用湿地数据比较四类图各自适合回答什么问题。它们共享一份 master table，差别只在视觉任务：筛查全局、定位 lineage、观察 taxonomy block、读取效应与区间。

::: {.callout-important title="先给结论"}
Volcano 的远点、cladogram 的彩色分支、Manhattan 的高峰和 forest 的置信区间必须能回到同一个 `FeatureID`、contrast 和 q-value。图形不能重新定义显著性。主分析使用 ANCOM-BC2；cladogram 另保留 LEfSe LDA score，但对全部 tested genera 追加 BH，并明确它是辅助 taxonomy view。Forest plot 承担定量解读，其他图只负责导航。
:::

本页使用 `microeco` 2.0.0 的真实湿地三件套，预声明 CW 对 IW。属级 feature selection 只看总体 prevalence 和总体 reads；未注释 residual 进入 denominator，却从四种图的生物学标注中排除。

## 四种图回答四个不同问题 {#sec-theory}

### Volcano：全表筛查，不是 effect uncertainty 图

横轴放 ANCOM-BC2 bias-corrected log fold change，纵轴放 $-\log_{10}(q)$。它同时显示方向与 statistical evidence，但不显示 standard error/CI 的宽度；极端点可能由稀疏、低 prevalence 或模型不稳定造成。标签只给预声明的少量 top rows，完整表另存。

### Cladogram：taxonomy context，不是系统发育树

Kingdom→Phylum→Class→Order→Family→Genus 的分类层级不是 branch-length phylogeny。Cladogram 可显示显著 genus 所在 lineage，却不能推出进化距离，也不能让 parent 自动继承 child 的显著性。本文只给通过 BH + LDA 门槛的 genus 叶节点着色，内部节点保持中性。

### Manhattan：看 taxonomy block 与集中性

横轴按 Phylum 和 genus 排序，纵轴仍是 $-\log_{10}(q)$。它适合发现信号是否集中在少数 phylum，也能显示 tested denominator；但 taxonomy 顺序不是连续基因组坐标，相邻点不代表遗传连锁。

### Forest：给出可解释的 effect 与 95% CI

对 coefficient $\hat\beta$ 和 standard error $SE$，Wald interval 为

$$
\hat\beta\pm1.96\,SE.
$$

Forest plot最接近可审稿的定量图：读者能看到方向、effect size 与 precision。CI 仍依赖模型假设；它不是 absolute abundance fold change，也不能替代 raw distribution 和 sensitivity analysis。

<details>
<summary><strong>深入：为什么 q-value threshold 与 effect threshold 要分开画</strong></summary>

`q<0.05`控制的是一组检验中的错误发现期望；`|log fold change|>=log(2)`是本页为了标签和视觉重点预声明的 practical-effect filter。后者不改变 q-value，也不应被描述为新的显著性检验。Volcano 中分别画横线和竖线，表格同时保留 `StatisticallySignificant` 与 `Highlighted` 两列。

</details>

  lefse_input,
  kruskal.threshold = 1,
  wilcox.threshold = 1,
  lda.threshold = 0,
  groupCol = "GROUP",
  checkAbundances = TRUE
)
lefse_scores <- setNames(lefse_fit$scores, lefse_fit$Names)
lefse_p <- vapply(rownames(counts), function(feature_id) {
  stats::wilcox.test(
    relative_per_million[feature_id, metadata$Group == "CW"],
    relative_per_million[feature_id, metadata$Group == "IW"],
    exact = FALSE
  )$p.value
}, numeric(1))
lefse_q <- stats::p.adjust(lefse_p, method = "BH")
descriptive_direction <- rowMeans(
  log2(counts[, metadata$Group == "CW", drop = FALSE] + 0.5)

  log2(counts[, metadata$Group == "IW", drop = FALSE] + 0.5)
)
lefse_results <- data.frame(
  FeatureID = rownames(counts),
  LDAScore = sign(descriptive_direction) * abs(lefse_scores[rownames(counts)]),

  Reportable = feature_info[rownames(counts), "Reportable"],
  stringsAsFactors = FALSE
)

## 常见坑 {#sec-pitfalls}

::: {.callout-caution title="坑 1：四张图各筛一套 taxa"}
先生成 master table，再写 deterministic view rule。图中任何点都应能用 `FeatureID` 回查 effect、SE、p、q、lineage 和 status。
:::

::: {.callout-caution title="坑 2：用 raw p 画 volcano，却标 q=0.05"}
纵轴变量与门槛必须一致。若画 `-log10(p)`，横线就是 raw-p 门槛；本文画 `-log10(q)`。
:::

::: {.callout-caution title="坑 3：在 volcano 标几十个名字"}
标签策略要预声明并限制数量；完整结果放表。重叠标签不是删掉不喜欢结果的理由。
:::

::: {.callout-caution title="坑 4：把 cladogram 当 phylogenetic tree"}
Taxonomic ranks 没有 branch length，也未使用 sequence alignment。若要进化解释，应另建 ASV tree 并做 phylogenetic analysis。
:::

::: {.callout-caution title="坑 5：让内部节点继承 LEfSe 显著性"}
Child hit 不证明 parent 或 sibling。内部节点只提供 context；每个 rank 的证据需要独立检验。
:::

::: {.callout-caution title="坑 6：Manhattan 只画显著点"}
保留全部 tested rows 才能看清 denominator、taxonomy block 和选择压力。只画 hits 会制造峰值密集的错觉。
:::

::: {.callout-caution title="坑 7：Forest 只给点估计"}
没有 SE/CI 的“森林图”只是条形图。报告 effect unit、contrast、interval method 与失败/非有限行。
:::

::: {.callout-caution title="坑 8：颜色方向在不同图中反转"}
固定正值 = CW higher、红 = CW、蓝 = IW；Methods、图例和结果表共享同一 mapping。不要按软件默认 level 临时换色。
:::

## 报告差异图的效应与筛选规则的方法与限制 {#sec-methods}

> Publication figures were generated from a single prespecified genus-level differential-abundance master table. ASVs were aggregated by complete taxonomic lineage; genera present in at least 10% of the 60 CW/IW samples and represented by at least 20 total reads were eligible, and 80 rows were retained using a group-blind prevalence × log(1 + total reads) score (79 reportable genera plus one non-reportable denominator residual). ANCOM-BC2 2.6.0 was fitted with `Group` as a fixed effect, IW as the reference, BH correction, and seed 20260733. Effects were oriented so that positive values indicated higher abundance in CW. Statistical significance was defined as q < 0.05; a prespecified |log fold change| >= log(2) threshold was used only for visual highlighting. Volcano and taxonomic Manhattan plots displayed all reportable tested genera. The forest plot displayed the 16 smallest-q significant genera with model-based Wald 95% confidence intervals. For the auxiliary cladogram, lefser 1.14.0 LDA scores were retained only for genera passing an all-feature Wilcoxon BH q < 0.05 and |LDA| >= 2; the 24 largest absolute LDA scores were displayed as colored genus leaves. Internal taxonomic nodes were not called significant, and the cladogram was not interpreted as a branch-length phylogeny. All plot labels were in English and figures were exported as PDF, SVG, 600 ppi PNG, and 600 ppi LZW-compressed TIFF.

替换主方法、effect unit、threshold、label count 和 CI method。若 primary model 使用 mixed effect、bootstrap 或 robust SE，forest plot 必须读取对应区间，不能用这里的 Wald 公式代替。
