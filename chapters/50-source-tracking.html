微生物来源追踪：SourceTracker / FEAST 与传播证据

作者

Peter

发布于

2026年9月6日

来源追踪估计贡献比例，不证明传播路径

Knights et al. (2011)提出 Bayesian SourceTracker；Shenhav et al. (2019)提出快速 expectation-maximization source tracking（FEAST）。以下分析使用 FEAST 官方真实 demo，对照 source contributions、method disagreement、leave-one-out calibration 与 missing-source 情形。

重要先给结论

两种方法都把 infant gut 1 sink 的最大已知来源判为 infant gut，但 FEAST 给 66.9%、Unknown 18.5%，SourceTracker2 给 92.9%、Unknown 0.44%。两者对 8 个可留一验证的 sources，其已知类别回判率都只有 50%。最大来源标签一致，不代表比例可互换；Unknown 更不是“真实未知比例”的直接测量。

来源追踪的结果取决于参考来源集

把待追踪样本看作多个候选来源的混合

设 source \(k\) 的 feature distribution 为 \(\theta_k\)，sink 的 mixture weights 为 \(\pi_k\)，则模型近似

\[ p(x_{\mathrm{sink}}) = \sum_{k=1}^{K}\pi_k\theta_k + \pi_U\theta_U, \qquad \sum_k\pi_k+\pi_U=1. \]

FEAST 用 expectation-maximization 快速估计；SourceTracker2 用 Bayesian Gibbs sampling。两者的 priors、source pooling、unknown model 与 optimization 不同，因此比例不应被视为算法无关的物理量。

来源库决定了贡献比例的含义

模型只能在你提供的 candidate sources 中分配。缺少真正来源时，信号可能进入 Unknown，也可能被最相似的已知 source 吸收。本页逐一删除 source class：删除 infant gut 后，FEAST Unknown 反而从 18.5% 降到 13.2%，其余权重被 adult skin/soil 吸收，直接说明 Unknown 不是“未采样来源”的单调计量器。

先用已知来源的样本检查模型

把一个已知 source sample 暂作 sink，并从对应 source pool 删除，再看是否回判到其真实 class。只有至少两个 replicates 的 class 才能做这种验证；本例 infant gut 只有一个 source，因此不参与 leave-one-out accuracy。

来源组成相似不等于菌株传播

16S/OTU-level source similarity无法区分共享高层 taxon、环境共同暴露与真正 donor-to-recipient transmission。传播结论至少需要高分辨率 strain/SNV sharing、方向与时间顺序、污染排除、背景人群比较，理想情况下再加 epidemiological contact 或 intervention evidence。

深入：Unknown 应怎样写进论文

Unknown 是“在给定 reference panel、特征空间、depth、prior/algorithm 下，无法由候选 sources 解释的模型分量”。它可能包含真正未采样来源、candidate source 内部变异、批次差异、测序误差、模型失配或过度平滑。最稳妥的写法是 model-dependent unexplained fraction，并同时给 missing-source sensitivity。

未知来源、留一校准与方法敏感性

  1. source panel 先于算法。candidate sources 应来自研究问题与 sampling design，而不是看完 sink 后补最相似的样本。
  2. negative controls 不能缺。extraction blanks、reagent lots 与 sequencing runs 应作为 contamination audit；低 biomass sinks 尤其不能把 kit contaminants 当来源。
  3. 匹配 feature space。所有 sources/sinks 必须同一 primer、region、pipeline、taxonomy/ASV universe；不同 studies 合并前要审 batch 与 zero inflation。
  4. Unknown 做 sensitivity，不做真值。本例删掉 infant gut 后 Unknown 没有上升，证明它依赖其余 source geometry 与算法。
  5. 留一验证暴露局限。两套方法已知 class accuracy 都只有 50%；主 sink 的最大类别一致不能抵消这一校准结果。
  6. 跨算法比较先统一 contract。本例统一 5,000 reads、source classes 与 seed；FEAST 给 point estimate，SourceTracker2 另给 20 draws 的 Monte Carlo SD，但这不是 biological confidence interval。
  7. 传播结论升级到 strain level。16S genus/OTU contribution 只能称 source attribution/similarity；transmission 需 shotgun SNVs/strain haplotypes、方向与时间证据。
警告不能这样写

“Infant gut contributed 92.9% of the sink, proving transmission”同时犯了两处错误：92.9% 是 SourceTracker2 在特定 reference panel 下的 model allocation；16S profile 也无法证明 donor、方向或 strain identity。

常见坑

注意审稿人最常追问的七件事
  1. source samples 在 sink 之后才按相似性选择，造成 circular reference panel。
  2. sources 与 sinks 来自不同 primer、batch、pipeline 或 feature definitions。
  3. 没有 extraction blanks/negative controls，尤其在低 biomass 场景。
  4. 不做 leave-one-out、synthetic mixture 或 external validation。
  5. 把 Unknown 当未采样来源的真实比例，且不给 missing-source sensitivity。
  6. 只跑一个 stochastic result，不设 seed、不报 chains/draws/burn-in/depth。
  7. 用 16S source attribution 宣称 direct transmission、donor identity 或传播方向。

报告来源追踪与校准的方法与限制

Source attribution was evaluated using the official FEAST example comprising one sink, nine source samples, four candidate source classes and 1,839 anonymous taxa. Count tables and metadata were aligned by exact sample identifier. FEAST v0.1.0 was run for 1,000 EM iterations at a coverage of 5,000 reads using seed 20260726, and sample-level weights were summed within pre-specified source classes. SourceTracker2 v2.0.1 used the same source classes and depth, alpha1=0.001, alpha2=0.001, beta=10, 10 restarts, two draws per restart, burn-in 100 and thinning delay 10. Classes with at least two source replicates were evaluated by leave-one-source-sample-out classification; FEAST was additionally rerun after removing each source class. Unknown was interpreted as a model-dependent unexplained fraction. Amplicon-level attribution was not considered evidence of strain transmission or directionality.

将来源追踪与校准用于自己的研究

  1. 替换三件套；metadata 至少增加 SourceSink 与预先定义的 SourceClass。FEAST 多 sink/source-set 设计还需正确的 id。
  2. sources/sinks 必须同批处理；若必须跨 study，先做 negative controls、batch sensitivity 与 matched-pipeline reprocessing。
  3. 每个 source class 尽量有多个 biological replicates；预留可做 leave-one-out 的样本，不要只给一个 pooled profile。
  4. 按最浅合理样本预设 analysis depth，并在多个 depths、priors 和 source panels 下做 sensitivity。
  5. 若研究问题是母婴、院内或食品链传播，另准备 shotgun metagenomes、采样时间、接触信息与 strain/SNV pipeline；不要靠本页的 proportions 完成传播结论。

## 来源追踪估计贡献比例，不证明传播路径 {#sec-target}

[Knights et al. (2011)](https://doi.org/10.1038/nmeth.1650)提出 Bayesian SourceTracker；[Shenhav et al. (2019)](https://doi.org/10.1038/s41592-019-0431-x)提出快速 expectation-maximization source tracking（FEAST）。以下分析使用 FEAST 官方真实 demo，对照 source contributions、method disagreement、leave-one-out calibration 与 missing-source 情形。

::: {.callout-important title="先给结论"}
两种方法都把 `infant gut 1` sink 的最大已知来源判为 `infant gut`，但 FEAST 给 66.9%、Unknown 18.5%，SourceTracker2 给 92.9%、Unknown 0.44%。两者对 8 个可留一验证的 sources，其已知类别回判率都只有 50%。**最大来源标签一致，不代表比例可互换；Unknown 更不是“真实未知比例”的直接测量。**
:::

## 来源追踪的结果取决于参考来源集 {#sec-theory}

### 把待追踪样本看作多个候选来源的混合

设 source $k$ 的 feature distribution 为 $\theta_k$，sink 的 mixture weights 为 $\pi_k$，则模型近似

$$
p(x_{\mathrm{sink}}) = \sum_{k=1}^{K}\pi_k\theta_k + \pi_U\theta_U,
\qquad \sum_k\pi_k+\pi_U=1.
$$

FEAST 用 expectation-maximization 快速估计；SourceTracker2 用 Bayesian Gibbs sampling。两者的 priors、source pooling、unknown model 与 optimization 不同，因此比例不应被视为算法无关的物理量。

### 来源库决定了贡献比例的含义

模型只能在你提供的 candidate sources 中分配。缺少真正来源时，信号可能进入 Unknown，也可能被最相似的已知 source 吸收。本页逐一删除 source class：删除 infant gut 后，FEAST Unknown 反而从 18.5% 降到 13.2%，其余权重被 adult skin/soil 吸收，直接说明 Unknown 不是“未采样来源”的单调计量器。

### 先用已知来源的样本检查模型

把一个已知 source sample 暂作 sink，并从对应 source pool 删除，再看是否回判到其真实 class。只有至少两个 replicates 的 class 才能做这种验证；本例 infant gut 只有一个 source，因此不参与 leave-one-out accuracy。

### 来源组成相似不等于菌株传播

16S/OTU-level source similarity无法区分共享高层 taxon、环境共同暴露与真正 donor-to-recipient transmission。传播结论至少需要高分辨率 strain/SNV sharing、方向与时间顺序、污染排除、背景人群比较，理想情况下再加 epidemiological contact 或 intervention evidence。

<details>
<summary><strong>深入：Unknown 应怎样写进论文</strong></summary>

Unknown 是“在给定 reference panel、特征空间、depth、prior/algorithm 下，无法由候选 sources 解释的模型分量”。它可能包含真正未采样来源、candidate source 内部变异、批次差异、测序误差、模型失配或过度平滑。最稳妥的写法是 model-dependent unexplained fraction，并同时给 missing-source sensitivity。

</details>

## 未知来源、留一校准与方法敏感性 {#sec-audit}

1. **source panel 先于算法。**candidate sources 应来自研究问题与 sampling design，而不是看完 sink 后补最相似的样本。
2. **negative controls 不能缺。**extraction blanks、reagent lots 与 sequencing runs 应作为 contamination audit；低 biomass sinks 尤其不能把 kit contaminants 当来源。
3. **匹配 feature space。**所有 sources/sinks 必须同一 primer、region、pipeline、taxonomy/ASV universe；不同 studies 合并前要审 batch 与 zero inflation。
4. **Unknown 做 sensitivity，不做真值。**本例删掉 infant gut 后 Unknown 没有上升，证明它依赖其余 source geometry 与算法。
5. **留一验证暴露局限。**两套方法已知 class accuracy 都只有 50%；主 sink 的最大类别一致不能抵消这一校准结果。
6. **跨算法比较先统一 contract。**本例统一 5,000 reads、source classes 与 seed；FEAST 给 point estimate，SourceTracker2 另给 20 draws 的 Monte Carlo SD，但这不是 biological confidence interval。
7. **传播结论升级到 strain level。**16S genus/OTU contribution 只能称 source attribution/similarity；transmission 需 shotgun SNVs/strain haplotypes、方向与时间证据。

::: {.callout-warning title="不能这样写"}
“Infant gut contributed 92.9% of the sink, proving transmission”同时犯了两处错误：92.9% 是 SourceTracker2 在特定 reference panel 下的 model allocation；16S profile 也无法证明 donor、方向或 strain identity。
:::

## 常见坑 {#sec-pitfalls}

::: {.callout-caution title="审稿人最常追问的七件事"}

1. source samples 在 sink 之后才按相似性选择，造成 circular reference panel。
2. sources 与 sinks 来自不同 primer、batch、pipeline 或 feature definitions。
3. 没有 extraction blanks/negative controls，尤其在低 biomass 场景。
4. 不做 leave-one-out、synthetic mixture 或 external validation。
5. 把 Unknown 当未采样来源的真实比例，且不给 missing-source sensitivity。
6. 只跑一个 stochastic result，不设 seed、不报 chains/draws/burn-in/depth。
7. 用 16S source attribution 宣称 direct transmission、donor identity 或传播方向。

:::

## 报告来源追踪与校准的方法与限制 {#sec-methods}

> Source attribution was evaluated using the official FEAST example comprising one sink, nine source samples, four candidate source classes and 1,839 anonymous taxa. Count tables and metadata were aligned by exact sample identifier. FEAST v0.1.0 was run for 1,000 EM iterations at a coverage of 5,000 reads using seed 20260726, and sample-level weights were summed within pre-specified source classes. SourceTracker2 v2.0.1 used the same source classes and depth, alpha1=0.001, alpha2=0.001, beta=10, 10 restarts, two draws per restart, burn-in 100 and thinning delay 10. Classes with at least two source replicates were evaluated by leave-one-source-sample-out classification; FEAST was additionally rerun after removing each source class. Unknown was interpreted as a model-dependent unexplained fraction. Amplicon-level attribution was not considered evidence of strain transmission or directionality.

## 将来源追踪与校准用于自己的研究 {#sec-own-data}

1. 替换三件套；metadata 至少增加 `SourceSink` 与预先定义的 `SourceClass`。FEAST 多 sink/source-set 设计还需正确的 `id`。
2. sources/sinks 必须同批处理；若必须跨 study，先做 negative controls、batch sensitivity 与 matched-pipeline reprocessing。
3. 每个 source class 尽量有多个 biological replicates；预留可做 leave-one-out 的样本，不要只给一个 pooled profile。
4. 按最浅合理样本预设 analysis depth，并在多个 depths、priors 和 source panels 下做 sensitivity。
5. 若研究问题是母婴、院内或食品链传播，另准备 shotgun metagenomes、采样时间、接触信息与 strain/SNV pipeline；不要靠本页的 proportions 完成传播结论。
